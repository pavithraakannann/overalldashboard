# Icon Files

Please add the following icon files to this directory:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can use any tree/green-themed icons. For quick setup:

1. Go to https://www.flaticon.com/search?word=tree
2. Download tree icons in the required sizes
3. Save them as icon16.png, icon48.png, and icon128.png

Or use a simple green square as a placeholder:
- Create a green square image in each size
- Save as PNG files
