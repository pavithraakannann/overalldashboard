# Icon Files Required

The Chrome extension requires icon files in the `icons/` folder. Since creating PNG images programmatically is complex without external libraries, please add the icons manually:

## Quick Solution

1. Download any tree/green icon from:
   - https://www.flaticon.com (search for "tree")
   - https://iconfinder.com (search for "tree")
   - Or use any icon you like

2. Resize to these sizes:
   - 16x16 pixels → save as `icons/icon16.png`
   - 48x48 pixels → save as `icons/icon48.png`
   - 128x128 pixels → save as `icons/icon128.png`

## Alternative: Use Online Generator

1. Go to: https://www.favicon-generator.org/
2. Upload any image
3. Download the generated icons
4. Rename them to icon16.png, icon48.png, icon128.png
5. Place in the icons/ folder

## Temporary Placeholder

For testing, you can create simple colored squares:
- Use any image editor (Paint, GIMP, etc.)
- Create 16x16, 48x48, and 128x128 purple squares
- Save as PNG files in the icons/ folder

The extension will work with any PNG images as icons.
